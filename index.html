프로젝트: 스타일 AI 🚀

AI를 활용한 개인 맞춤형 코디 제안 서비스

"오늘 뭐 입지?" - 매일 반복되는 고민

출근, 등교, 약속 등 매일 아침 어떤 옷을 입어야 할지에 관한 고민은 스트레스, 시간 낭비, 심지어는 불필요한 충동 구매로 이어지는 일상적인 문제입니다.

본 프로젝트는 개인의 옷장 데이터와 실시간 외부 환경 데이터를 결합하여, 사용자의 고민을 해결하는 현실적이고 감각적인 코디 제안 서비스를 제공하는 것을 목표로 했습니다.

하이브리드 아키텍처

생성형 AI (LLM) 기술을 활용하여 사용자에게 코디를 제안하는 하이브리드 설계입니다. 옷장 데이터는 구조화된 형태로 DB에 저장되며, 백엔드에서 날씨/트렌드 데이터를 결합하여 자연어 처리(NLP)를 통해 프롬프트를 생성합니다. 이 데이터를 기반으로 LLM이 새로운 코디를 만들어내고, 그 결과를 사용자에게 출력하는 방식으로 설계되었습니다.

시스템 흐름도

Client (React)

기능 1: 상황별 맞춤 코디 (LLM 생성)

사용자가 상황을 입력하면, AI가 새로운 스타일을 창의적으로 생성하여 제안합니다.

AI 제안 (시뮬레이션):

"클라이언트 요청을 Flask 서버가 받고, '비', '실내', '데이트' 키워드를 추출합니다. LLM에게 최적의 프롬프트를 전달하여, '차분한 톤의 니트와 코튼 팬츠' 같은 창의적인 코디를 생성해 반환합니다."

기능 2: 개인 옷장 기반 조합 추천

사용자가 텍스트로 입력한 옷 중에서 가장 좋은 조합을 추천하거나 보완할 아이템을 제안합니다.

내 옷장 (DB 예시)

  • 아이템: 검은색 슬랙스 (하의, 사계절)
  • 아이템: 흰색 옥스포드 셔츠 (상의, 봄/가을)
  • 아이템: 베이지색 트렌치 코트 (아우터, 봄)

AI 제안 (시뮬레이션):

"백엔드에서 DB의 옷 정보, 실시간 날씨, 트렌드 키워드를 조합하여 '오늘 날씨엔 셔츠와 트렌치 코트 조합이 적절합니다' 같은 맞춤형 코디를 생성하고 사용자에게 전달합니다."

나의 역할 및 기여 📌

  • Python Flask를 활용하여 옷장 코디 추천 시스템의 백엔드 아키텍처를 구축하고, API 엔드포인트를 설계했습니다.
  • 날씨 API 연동 및 트렌드 키워드 처리 모듈을 구현하여, 외부 환경 데이터를 실시간으로 코디 로직에 통합했습니다.
  • 트렌드 가중치 기반의 조합 알고리즘을 구현하여, DB에 저장된 사용자별 옷장 아이템에서 현실적이고 감각적인 맞춤형 코디 제안 기능을 성공적으로 서비스화하는 데 기여했습니다.
  • LLM API 연동 로직을 설계하고 프롬프트 템플릿을 구성하여, 상황별 맞춤 코디 생성 기능을 구현했습니다.

결과 및 성과 📈

  • 날씨, 트렌드, 패션 규칙에 기반한 가중치 알고리즘을 적용하여, 단순 매칭 대비 추천 정확도를 20%p (15% → 35%) 향상시켰습니다.
  • 핵심 추천 로직에 대한 단위/통합 테스트를 작성하여 시스템의 잠재적 오류를 사전에 방지하고 서비스 장애 발생률을 최소화했습니다.

배운 점 💡

생성형 AI(Generative AI)를 활용할 경우, 복잡한 규칙 기반 로직이나 대규모 데이터셋 구축 없이도 창의적이고 비정형적인 결과물을 도출할 수 있음을 확인했습니다. 이를 통해 AI의 활용 범위가 특정 분야에 국한되지 않고 서비스의 모든 측면에서 사용될 수 있음을 깊이 있게 이해했습니다.

개선점 🧭

프로젝트 초기 계획은 사진을 찍으면 옷장에 저장되는 방식 (이미지 분석)으로 구현하려고 했으나, 예상보다 훨씬 높은 난이도로 인해 시간문제로 구현하지 못하고 텍스트 입력 방식으로 대체되었습니다. 향후 이미지 인식 딥러닝 모델 (예: YOLO 또는 CNN 기반 분류 모델)을 추가적으로 학습하여 비정형 이미지 데이터를 처리하는 기능을 구현함으로써 서비스의 사용자 경험(UX)을 획기적으로 개선하고 싶습니다.
